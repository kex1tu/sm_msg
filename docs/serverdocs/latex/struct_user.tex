\doxysubsection{Detailed Description}
Представляет собой модель данных одного пользователя в приложении. 

Эта структура используется для хранения и передачи всей информации, связанной с конкретным пользователем, как в кэшах на клиенте, так и для временного представления данных, полученных от сервера.
