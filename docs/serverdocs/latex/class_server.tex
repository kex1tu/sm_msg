\doxysubsection{Detailed Description}
Главный класс, реализующий логику чат-\/сервера. 

Этот класс управляет TCP и Web\+Socket серверами, обрабатывает подключения клиентов, аутентифицирует их, обрабатывает их запросы (отправка сообщений, поиск, управление контактами и т.\+д.), взаимодействует с базой данных SQLite для хранения информации и управляет состоянием онлайн-\/пользователей.

Рассылает всем онлайн-\/клиентам актуальный список пользователей, находящихся в сети. 

Этот метод получает список имен пользователей из ключей карты {\ttfamily m\+\_\+clients}, что представляет собой полный список всех аутентифицированных и подключенных в данный момент клиентов. Затем он формирует JSON-\/сообщение с типом "{}user\+\_\+list"{} и отправляет его каждому клиенту из списка {\ttfamily m\+\_\+clients}. Обычно вызывается после успешного входа пользователя или после его отключения, чтобы все клиенты могли обновить свои списки контактов, отображая актуальный онлайн-\/статус.

\item Отправка push-\/уведомления целевому пользователю, если он онлайн.

Отправляет клиенту счетчики непрочитанных сообщений, сгруппированные по отправителям. 

Эта функция вызывается после успешного входа пользователя в систему. Она выполняет SQL-\/запрос к таблице {\ttfamily messages}, чтобы найти все сообщения, адресованные данному пользователю ({\ttfamily username}), которые еще не были помечены как прочитанные ({\ttfamily is\+\_\+read = 0}). Это позволяет клиентскому приложению отображать "{}бейджи"{} с количеством новых сообщений рядом с именами контактов.
