\doxysubsection{Detailed Description}
Точка входа в серверное приложение чата. 

Этот файл содержит функцию {\ttfamily main}, которая является первой функцией, вызываемой при запуске сервера. Ее основные задачи\+:
\begin{DoxyEnumerate}
\item Создать экземпляр {\ttfamily QCore\+Application} -\/ ядро любого консольного Qt-\/приложения.
\item Создать главный объект сервера ({\ttfamily \doxylink{class_server}{Server}}).
\item Запустить сервер для прослушивания входящих подключений.
\item Запустить главный цикл обработки событий Qt, который будет поддерживать работу сервера в асинхронном режиме. 
\end{DoxyEnumerate}
