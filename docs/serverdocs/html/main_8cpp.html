Detailed Description

Точка входа в серверное приложение чата.

Этот файл содержит функцию main, которая является первой функцией, вызываемой при запуске сервера. Ее основные задачи:

  1. Создать экземпляр QCoreApplication - ядро любого консольного Qt-приложения.
  2. Создать главный объект сервера (Server).
  3. Запустить сервер для прослушивания входящих подключений.
  4. Запустить главный цикл обработки событий Qt, который будет поддерживать работу сервера в асинхронном режиме.
