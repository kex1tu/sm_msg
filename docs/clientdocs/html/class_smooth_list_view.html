Detailed Description

Кастомный класс QListView, обеспечивающий плавную попиксельную прокрутку.

Этот класс наследуется от QListView и переопределяет его поведение, связанное с прокруткой и компоновкой, для достижения более плавного и современного пользовательского опыта, характерного для мобильных приложений и современных мессенджеров.

Ключевые особенности:

  1. Включает режим попиксельной прокрутки (ScrollPerPixel).
  2. Снижает интенсивность прокрутки колесом мыши для более точного контроля.
  3. Использует пакетную компоновку (Batched layout mode) для повышения производительности при работе с большим количеством элементов.
