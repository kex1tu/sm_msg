Detailed Description

Виджет, отвечающий за отображение интерфейса одного чата.

Этот класс инкапсулирует всю визуальную часть диалога: заголовок, историю сообщений и панель ввода. Он не содержит бизнес-логики, а только отображает данные и уведомляет MainWindow о действиях пользователя через сигналы.
