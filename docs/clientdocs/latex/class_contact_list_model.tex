\doxysubsection{Detailed Description}
Кастомная модель данных для списка контактов. 

Этот класс выступает в роли адаптера (Proxy) между централизованными кэшами данных, хранящимися в \doxylink{class_main_window}{Main\+Window}, и представлением (QList\+View).

Он не дублирует данные, а лишь хранит отсортированный список идентификаторов (usernames) и предоставляет унифицированный интерфейс для делегата (\doxylink{class_contact_list_delegate}{Contact\+List\+Delegate}) для получения информации о контактах через кастомные роли. \begin{DoxyAuthor}{Author}
