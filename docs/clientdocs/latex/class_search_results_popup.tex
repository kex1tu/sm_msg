\doxysubsection{Detailed Description}
Всплывающий виджет для отображения списка пользователей, найденных в результате глобального поиска. 

Этот класс представляет собой самодостаточный, всплывающий (Qt\+::\+Popup) виджет, который появляется под строкой поиска. Он получает данные в виде QJson\+Array, отображает их в виде списка и уведомляет родительский виджет о выборе пользователя через сигнал \doxylink{class_search_results_popup_ad488c35265a75f5462fa27ee8d3f8779}{user\+Selected()}. \begin{DoxyAuthor}{Author}

Заполняет виджет результатами поиска и отображает его. 

Заполняет виджет результатами поиска, настраивает его размер и отображает.

Этот метод очищает предыдущий список, заполняет его новыми данными из {\ttfamily users}, динамически настраивает свою высоту в зависимости от количества результатов и отображает себя на экране.
