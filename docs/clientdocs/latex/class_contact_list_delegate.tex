\doxysubsection{Detailed Description}
Кастомный делегат для отрисовки элементов в списке контактов (QList\+View). 

Этот класс полностью отвечает за визуальное представление каждого контакта в списке. Он не хранит никаких данных, а получает всю необходимую информацию для отрисовки напрямую из модели (\doxylink{class_contact_list_model}{Contact\+List\+Model}) через {\ttfamily QModel\+Index} и кастомные роли.

В обязанности делегата входит отрисовка\+:
\begin{DoxyItemize}
\item Двухстрочного представления\+: Имя пользователя и превью последнего сообщения.
\item Визуального статуса "{}онлайн"{} (жирный шрифт).
\item Статуса "{}печатает..."{}.
\item "{}Бейджа"{} с количеством непрочитанных сообщений. \begin{DoxyAuthor}{Author}
kex1tu 
\end{DoxyAuthor}

\end{DoxyItemize}
