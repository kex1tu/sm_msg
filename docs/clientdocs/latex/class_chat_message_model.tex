\doxysubsection{Detailed Description}
Макрос Qt, регистрирующий кастомный тип \doxylink{struct_chat_message}{Chat\+Message} в мета-\/объектной системе Qt. 

Это необходимо для того, чтобы мы могли\+:
\begin{DoxyEnumerate}
\item Оборачивать объекты \doxylink{struct_chat_message}{Chat\+Message} в QVariant (чтобы передавать их через \doxylink{class_chat_message_model_ab687665d0889263fab9c116c8d604814}{data()} модели).
\item Использовать этот тип в механизме сигналов и слотов. \begin{DoxyAuthor}{Author}
kex1tu
\end{DoxyAuthor}
Модель данных для списка сообщений в одном чате.
\end{DoxyEnumerate}

Этот класс является "{}источником правды"{} для {\ttfamily QList\+View}, который отображает чат. Он наследуется от QAbstract\+List\+Model, реализуя его виртуальные методы для предоставления данных представлению (View).

Модель ничего не знает о том, как данные будут отображаться; она только хранит их и уведомляет представление об изменениях.
