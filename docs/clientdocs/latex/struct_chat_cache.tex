\doxysubsection{Detailed Description}
Структура для кэширования истории одного чата в оперативной памяти клиента. 

Используется в {\ttfamily \doxylink{class_main_window}{Main\+Window}} для мгновенного отображения переписок при переключении между контактами без повторных запросов к серверу.
