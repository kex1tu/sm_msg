\doxysubsection{Detailed Description}
Главное окно и центральный контроллер ("{}мозг"{}) всего клиентского приложения. 

Этот класс выполняет роль "{}дирижера"{}, координируя работу всех остальных компонентов\+:
\begin{DoxyItemize}
\item Управляет сетевым соединением и обрабатывает протокол обмена данными с сервером.
\item Хранит всё состояние приложения (кэши, текущего пользователя, текущий чат).
\item Собирает основной пользовательский интерфейс из составных виджетов.
\item Связывает сигналы от UI-\/элементов со слотами бизнес-\/логики. \begin{DoxyAuthor}{Author}

\end{DoxyAuthor}

\end{DoxyItemize}
