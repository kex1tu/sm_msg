\doxysubsection{Detailed Description}
Кастомный класс QList\+View, обеспечивающий плавную попиксельную прокрутку. 

Этот класс наследуется от QList\+View и переопределяет его поведение, связанное с прокруткой и компоновкой, для достижения более плавного и современного пользовательского опыта, характерного для мобильных приложений и современных мессенджеров.

Ключевые особенности\+:
\begin{DoxyEnumerate}
\item Включает режим попиксельной прокрутки ({\ttfamily Scroll\+Per\+Pixel}).
\item Снижает интенсивность прокрутки колесом мыши для более точного контроля.
\item Использует пакетную компоновку ({\ttfamily Batched} layout mode) для повышения производительности при работе с большим количеством элементов. \begin{DoxyAuthor}{Author}

\end{DoxyAuthor}

\end{DoxyEnumerate}
