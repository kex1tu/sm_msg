\doxysubsection{Detailed Description}
Кастомный QText\+Edit с плавной анимацией прокрутки. 

Этот класс наследуется от QText\+Edit и переопределяет стандартное поведение прокрутки колесом мыши. Вместо мгновенного "{}прыжка"{} скроллбара, он использует QProperty\+Animation для создания плавной и анимированной прокрутки содержимого, если текст не помещается в видимую область. \begin{DoxyAuthor}{Author}
